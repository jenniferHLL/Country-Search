# Countries Search

## Description

Countries Search is a Python command-line application that gets country data from an API. Users can search and compare information about countries.

## Features

- Filter countries by region
- Find the largest country by area
- Find the most populous country
- Compare two countries

## Installation

Install the required package:

pip install -r requirements.txt

## How to Run

Run the program with:

python main.py

## How to Use

Choose an option from the menu and follow the instructions shown in the terminal.
